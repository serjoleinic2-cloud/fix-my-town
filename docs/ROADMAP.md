## Приоритет угроз (последнее уточнение владельца)
1. **Следующий этап: пожарная служба и один распространяющийся пожар.** Своё депо/машина; предупреждение/таймер, повреждения, остановка распространения при прибытии, тушение и последующий ремонт. Активные события/поручения сохраняются; снос депо при выезде запрещён.
2. **После проверки пожара: электричество и ночь.** Ограниченная мощность/потребление, станция с улучшениями, подключение вдоль дорог одним действием, активный цикл света, ночные окна/фонари, влияние отключения.
3. **Позже: заболевания и недовольство.** Стадии по зданиям, больница/выезды, жалобы и мирные забастовки через устранение причин; полиция только для насилия и порчи имущества.

Для всех этапов: лимит одновременных событий, спокойный старт, нет офлайн-ухудшения, восстановление повреждений, предупреждение перед разрушением, сохранение всех стадий/подключений. Прохожие/магазин из 2А остаются согласованным контентом, новый приоритет — проверка одного пожара.
