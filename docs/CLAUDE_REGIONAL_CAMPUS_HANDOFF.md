# Fix My Town — handoff для Claude: региональные кампусы

Дата: 27 ноября 2026. Основная ветка: `codex/city-modernization`.

## Цель

Город должен постепенно вырастать в региональный центр. За пределами городской сетки нужны четыре большие, самостоятельные локации: аэропорт, железнодорожный узел, энергетический комплекс и фермерский кампус за рекой. Это должны быть реальные игровые районы, а не цветные маркеры.

Игрок должен видеть их в режиме «Обзор региона», понимать масштаб и постепенно открывать инфраструктуру по этапам.

## Уже сделано

- Внешние зоны вынесены за пределы городской сетки.
- Позиции заданы мировым планом и не должны вычисляться от текущей камеры или края видимых зданий.
- Активные зоны:
  - аэропорт: слева, примерно `(-105, 0, 0)`;
  - депо: справа, примерно `(100, 0, -28)`;
  - энергетика: сверху, примерно `(0, 0, -112)`;
  - ферма: снизу за рекой, примерно `(95, 0, 112)`.
- Для зон есть отдельные площадки, расширенный terrain, река, обзор региона и внешний туман.
- Убрана горная гряда, которая выглядела отдельными кусками.
- Река продолжена к внешней границе мира.
- Есть процедурные заготовки деталей: терминал, самолёты, телетрапы, пути, поезд, панели, ветряки, поля, амбар, силос и техника.

## Что сейчас не устраивает

1. На телефоне старые сборки показывали большие одноцветные пятна вместо читаемых кампусов. Проверять нужно именно после pull последнего коммита, а не по старому APK.
2. Нужен масштаб «мини-города», а не объект размером с один дом.
3. Между кампусами и городской зоной должны быть понятные подъездные дороги/коридоры, но кампусы не должны занимать клетки городской сетки.
4. Ферме нужен большой запас свободной земли для будущих полей, животных, мельницы, пекарни и складов. Депо нельзя ставить вплотную к ферме.
5. Детали должны сохранять собственные цвета. Нельзя использовать один материал на весь кампус.
6. Дальний мир должен закрываться неоднородным туманом. Не показывать пустой прямоугольный край и не возвращать горы.

## Требования к моделям

### Аэропорт

Терминал с фасадом и окнами, диспетчерская башня, ВПП, рулёжные дорожки, перрон, две стоянки самолётов, телетрапы, автобус, багажный тягач, топливная/служебная зона. Самолёты должны быть заметно крупнее машин города.

### Железнодорожный узел

Отдельная станция, минимум три параллельных пути, платформы, навес, сигнализация, поезд, грузовой двор, контейнеры и ремонтный корпус. Пути должны визуально выходить из кампуса в сторону будущего расширения.

### Энергетика

Отдельные блоки солнечных панелей, несколько ветряков на расстоянии друг от друга, подстанция, аккумуляторный блок, силовые линии и промышленный корпус. Развитие по этапам: солнце → ветер → накопители/подстанция → полноценная станция.

### Ферма

Большая зона за рекой: поля разных размеров, амбар, фермерский склад, силосы, мельница, пекарня/переработка, пастбище, ограждения, ирригация, техника. Поля должны оставлять свободное место для дальнейшего строительства.

## Правила реализации

- Не менять сохранение игрока и не сбрасывать город.
- Не привязывать мировые позиции к `CityCenter`, bounding box города или камере после создания плана.
- Проверять мировые AABB кампусов и гарантировать отсутствие пересечений.
- Кампусы должны быть видимы в обзоре региона и по отдельным кнопкам фокусировки.
- Не использовать `no_depth_test` для 3D-моделей кампусов: дальний объект не должен рисоваться поверх города.
- Не делать новые яркие ромбы/площадки, маскирующие отсутствие модели.
- Сохранять мобильную производительность: модульные low-poly детали, без тысяч отдельных тяжёлых объектов.
- Сначала сделать визуальную геометрию и размещение, затем добавить анимации: самолёт прилетает/уезжает, поезд движется, ветряки вращаются, техника работает.

## Проверка перед APK

1. Pull последней ветки.
2. Headless import без Parse Error.
3. Запустить новый город/демо-город без изменения сохранения пользователя.
4. В обзоре региона проверить четыре отдельные зоны и отсутствие наложения.
5. Проверить фокус каждой зоны и возврат к городу.
6. Только после этого собрать APK и установить поверх игры без очистки данных.

Текущие последние изменения касаются только визуала/террейна региональных зон. Старые транспортные и городские механики не переписывать в рамках этой задачи.
