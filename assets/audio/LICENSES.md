# Источники и лицензии звуков

Все текущие WAV — временные оригинальные процедурные звуки, созданные для Fix My Town скриптом `tools/generate_audio.py`. Сторонние записи, голоса людей, библиотеки семплов и музыка не использовались. Генерация воспроизводима: Python 3, стандартная библиотека, seed 42, моно PCM 16 bit / 22050 Hz.

Для этих процедурных аудиофайлов и скрипта генерации применяется CC0 1.0 Universal: https://creativecommons.org/publicdomain/zero/1.0/ . Допускается коммерческое использование, изменение и распространение без указания авторства. Это не заявление о лицензии остального проекта.

- `click.wav`, `select.wav`, `deny.wav`, `cancel.wav` — отклики интерфейса; источник: собственный синтез; CC0-1.0.
- `success.wav`, `level_up.wav` — подтверждение результата и завершение этапа; собственный синтез; CC0-1.0.
- `siren.wav`, `engine.wav` — выезд и двигатель службы; собственный синтез; CC0-1.0.
- `water.wav`, `repair.wav`, `build.wav` — протечка, инструменты, строительство; собственный синтез; CC0-1.0.
- `leaves.wav`, `reaction.wav` — листва и условная бессловесная реакция жителей; собственный синтез; CC0-1.0.
- `city.wav`, `birds.wav` — фон района и условные птицы; собственный синтез; CC0-1.0.
- `warning.wav` — ограниченное по частоте предупреждение; собственный синтез; CC0-1.0.

Перед заменой каждого семпла добавить сюда точное имя файла, автора, исходный URL, название/версию лицензии и требуемую атрибуцию. Использовать только собственное производство либо разрешение на коммерческое использование. Синтез служит проверке системы; качество полевых записей пока не заявляется.
