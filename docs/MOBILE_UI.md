# Мобильный интерфейс и качество

## Экран и безопасная область
База портретного интерфейса — 540 × 1200. Контейнеры пересчитывают размеры по доступному экрану; безопасная область запрашивается через DisplayServer на Android. Верхний HUD и нижние интерактивные элементы учитывают вырезы и системную навигацию. В тестах дополнительно подставляются верхний отступ 40 и нижний 36 единиц.

Главные кнопки, отмена, закрытие, переключатели и зоны маркеров имеют минимум 72 единицы при ширине базы 540. При логической ширине 360 это соответствует 48 единицам нажатия. Карта доступна для перетаскивания; масштаб меняется колесом либо кнопками в меню. Симуляция и звук приостанавливаются при потере фокуса.

## Качество карты
Профиль выбирается в меню справа и сохраняется в `user://graphics_settings.json`, отдельно от игрового района.

- **Высокое**: 3D-разрешение учитывает плотность экрана (до коэффициента 2), тени, MSAA 4×, 24 транспортных средства, ограничение 60 FPS.
- **Сбалансированное**: 3D-разрешение уменьшено вдвое, тени, MSAA 2×, 16 транспортных средств, ограничение 60 FPS. Это начальное качество на мобильной платформе.
- **Экономное**: 3D-разрешение уменьшено втрое, без теней и MSAA, восемь транспортных средств, ограничение 30 FPS. Предназначено в том числе для проверки на Galaxy A22.

Это ограничения движка, а не обещание достигнутого FPS. 2D-интерфейс не уменьшается вместе с картой. Статичная геометрия объединена через MultiMesh; динамические окна/состояния сохранены отдельно.

## Разрешения для проверки
- 840 × 1870 — одинаковый размер трёх портретных референсов и снимков игры.
- 1080 × 2400 — профиль Galaxy S21+; [данные Samsung](https://www.samsung.com/us/business/support/owners/product/galaxy-s21-plus-5g-unlocked/).
- 720 × 1600 — профиль Galaxy A22 LTE; не путать с A22 5G, у которого другой экран. [Профили Samsung Developer](https://developer.samsung.com/galaxy-emulator-skin/galaxy-a.html).
- 360 × 800 — логический компактный экран для проверки размеров нажатий; 540 × 960 — дополнительная пропорция 16:9.

`tests/responsive_ui_test.gd` проверяет безопасные отступы, границы панелей, доступность отмены, ввод при изменении 3D-разрешения, построение кнопкой, отсутствие списания при отмене и сохранение профиля.

## Настоящая Android-сборка
`export_presets.cfg` содержит отладочный arm64 APK `org.fixmytown.prototype`, без доступа к интернету. Нужны Godot 4.6 Standard, соответствующий Android debug export template, Android SDK и JDK. [Требования Godot](https://docs.godotengine.org/en/4.6/tutorials/export/exporting_for_android.html).

```powershell
godot --headless --path D:\fix-my-town --export-debug Android C:/Temp/fix-my-town-debug.apk
adb install -r --user 0 C:/Temp/fix-my-town-debug.apk
```

Подпись — локальный отладочный keystore Godot; ключи и пути пользовательского SDK не хранятся в репозитории. Это отладочная установка для тестирования, не публикация в магазине. Обновление через `-r` сохраняет данные приложения. Релизная сборка отдельно настраивается с собственным ключом.

В Android debug-сборке раз в пять секунд выводится `FMT_METRICS`: профиль, FPS движка, разрешение карты, число draw calls и безопасные отступы. Получать только журнал процесса игры; не сохранять общий журнал телефона и личные идентификаторы. Итоги проверки конкретного устройства записываются в PROJECT_STATE.md.

## Основа реализации
[DisplayServer.get_display_safe_area](https://docs.godotengine.org/en/4.6/classes/class_displayserver.html) задаёт область интерактивных элементов. [SubViewportContainer.stretch_shrink](https://docs.godotengine.org/en/4.6/classes/class_subviewportcontainer.html) снижает разрешение только карты; экранный интерфейс остаётся отдельным CanvasLayer.

## Панели состояния и транспорта
Обычная карта не показывает шкалу качества жизни сверху. Кнопка «Состояние» справа включает окраску и легенду; сведения района доступны во вкладке «Район». По нажатию на дом — состояние, максимум две причины и действие; числа только в «Подробнее». BUS открывает остановки/маршрут после первого сценария. Панели дополнительно проверены в RU/EN при ширине 360 и безопасных отступах; минимум кнопок 72 сохранён. Положение/минимальный размер панели пересчитываются при переносах текста, чтобы длинные русские строки не расширяли её за экран.
