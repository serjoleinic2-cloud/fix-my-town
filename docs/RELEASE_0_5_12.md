# Обновление 0.5.12 — 04.11.2026

- Элитный дом занимает 2×2, как обычный жилой участок. Для него не нужны два
  жетона сноса, объединение участков или проезд под аркой. Цена — 1200 монет.
- Стройку окружает высокая полупрозрачная светящаяся завеса 3,2 м.
- Возвращён ограниченный трафик нового города: реальные дорожные клетки,
  разные скорости и повороты, сигналы, дистанция и дорожные блокировки.
- Автобус больше не зависит от устаревшего задания ремонта. Со второго этапа
  можно поставить две остановки и запустить маршрут из «Район → Транспорт».
- Включены ранее проверенные локальные исправления: площадки материалов,
  видимое улучшение, песочная свободная земля, зебра, безопасные диалоги,
  отсутствие отдельной BUS и сохранение ветшания домов.
